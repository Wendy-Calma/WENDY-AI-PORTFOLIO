Pair 1 · ChatGPT

"Which one is better?"

Original prompt 
Which one is better?

ChatGPTIt depends on what you're comparing. Could you tell me which two (or more) things you mean?

It then listed random example comparisons, like Windows vs Linux and Python vs Java.

Improved prompt 
Which is better for a small university website with mostly static pages: a traditional content management system or a custom web application? Consider cost, maintenance, and technical expertise.

ChatGPTFor a small university website with mostly static pages, a traditional Content Management System (CMS) is generally the better choice.

It followed with a table using exactly my three criteria, and said a custom app makes more sense for things like a student portal or enrollment system.

Expected: a direct recommendation for my situation. Actual: the first prompt got a question back; the second got the recommendation.

What changed and why it worked

The second prompt gives the context (small university, static pages), the options to compare and the criteria to judge them by. The first prompt left all three for the AI to guess. Asking back was actually the right move for a vague question, but it cost an extra turn.

Pair 2 · ChatGPT

Summarizing an outage report

Both prompts summarize the same incident report: the university LMS went down on August 12 after a new version was deployed. The report says a connection leak is only suspected, an audit is still running, and no prevention plan has been approved.

Expected: a summary a manager can act on that only states what the report supports.

Original prompt 
Summarize this incident report:
[report text]

Three accurate paragraphs in time order. A general reader would be fine, but a manager would have to dig for the root cause, the impact and what happens next.

Improved prompt 
Summarize the incident for an IT manager. Include: impact, affected services, root cause, resolution, and three preventive actions. Limit the words to 150. If evidence is missing, write "not established."
[report text]

ChatGPT (excerpt)Root cause: Not established. Preliminary logs suggest the newly deployed application version may have contained a database connection leak.

Checking the improved output against its own instructions
InstructionWhat I foundResult
Written for an IT manager, 5 fieldsAll five labeled fields are thereMet
150 words or fewer136 words (I counted)Met
"Not established" for missing evidenceUsed for the root causeMet
Stay true to the reportListed three preventive actions without saying none have been approvedPartly
Complete impactLeft out that the submission and quiz audit is still in progressPartly

What I noticedMy prompt asked for three preventive actions, so the AI gave three, even though the report says no plan exists. A request can push the model to fill a gap. Next time I'd write "suggest three preventive actions and label them as suggestions."

Anatomy · ChatGPT

My personalization interview prompt

The most structured prompt I wrote. Instead of describing myself, I made ChatGPT interview me and then write its own Custom Instructions and memory policy.

Expected: one question at a time, then the final personalization. Actual: 10 questions, each ending with "Why this question matters," some push-back on my answers, and the personalization only after the last one. I tested the result on the Projects page.

PartWhat I wrote (shortened)
Role"I want you to act as an expert personalization consultant for ChatGPT."
GoalCreate the best possible Custom Instructions and Memory preferences through a structured interview.
RulesAsk only ONE question at a time. Build on my previous answers. Follow up when an answer is vague. Challenge assumptions instead of agreeing. Explain why the next question matters.
Coverage20 topics, including how I learn, how detailed I want answers, how to show uncertainty, and what should never be remembered.
OutputAn "About Me," a "How I'd Like ChatGPT to Respond," a memory policy, the reasoning, and things I overlooked.
Stop rule"Do not generate the final personalization until the interview is complete."

Jayjay's system prompt, first version to final

The first version is from the starter code I committed on September 10. The final version is on main after Harman's November 14 update. Both are quoted from our GitHub repository.

First version (Sept 10) 
You are the customer support assistant for J&J Egg Supply, a small student-run egg business.

Rules you must always follow:
1. Only use facts found inside the <context> block below. Never invent prices, stock levels, policies, or delivery details that are not in <context>.
2. If the answer is not fully supported by <context>, reply with exactly this sentence and nothing else: "{fallback}"
3. Be warm, brief, and clear. This is a chat conversation, not an essay.

<context>
{context}
</context>
Final version (Nov 14, excerpt) 
LANGUAGE
- Look at the customer's LATEST message and reply in that language: English -> English only. Tagalog -> Tagalog. Taglish (mixed) -> Taglish.

TAGALOG WORDS CUSTOMERS USE
- tray / bandehado = one tray of 30 eggs
- kaha = case/box (ask how many trays they mean)

FACTS (the ONLY information you may use)
{facts}

RULES
1. Use ONLY the facts above. Never invent prices, discounts, stock, fees, delivery schedules, or any other detail. If the answer is not in the facts, say you are not sure and give the staff contact number {contact}.
...
When you have ALL the details, do NOT calculate the total yourself.
...
Never say the order is confirmed, final, or ready; say our staff will confirm it.
