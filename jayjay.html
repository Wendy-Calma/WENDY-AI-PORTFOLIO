Jayjay, the J&J Egg Supply chatbot

Team EggDroids: Wendy Calma, Justine Esguerra, Harman Magar Built with: Python (Flask), Google Gemini, Google Sheets, Messenger, Render Status: Live on the J&J Facebook Page View the code on GitHub

J&J Egg Supply sells eggs by the tray and rice by the sack in Angeles City. Their customers already message the Facebook Page, so we built Jayjay to answer those messages: prices, stock, delivery, payment and orders.

The hard part wasn't getting the AI to talk. It was keeping it from inventing a price, a discount or a delivery promise for a real business. Most of our work went into rules, checks and hand-offs to staff.

Justine handled the backend and the Messenger integration. Harman built the AI, LLM and ordering logic.

My part: project manager, BA and QA

  • Worked with J&J's owners and confirmed all 9 knowledge categories
  • Got Meta Business Suite access to J&J's Facebook Page
  • Wrote the SRS, and set up the GitHub repo and starter code
  • Kept the knowledge base current, like updating Medium eggs to ₱238 per tray
  • Tested orders on Messenger in English and Taglish, and reported bugs

How Jayjay handles a message

  1. A customer messages the Page, and Meta sends it to our Flask backend on Render.
  2. The backend rebuilds the prompt with the current facts: prices and stock from the Google Sheet, and delivery, payment and promos from JSON files. It also tells the model to reply in English, Tagalog or Taglish.
  3. Gemini 3.5 Flash Lite writes the reply. If it's busy, Gemini 3.6 Flash takes over.
  4. The backend blocks any ₱ amount that isn't a real price or a valid order line. For orders, it calculates the total itself.
  5. The order saves only after the customer confirms the summary, and it waits for staff to confirm. Rice delivery outside Angeles City, complaints and haggling go straight to staff.

An earlier version overclaimed

Our older web chat ended an order with "Inihahanda na po namin ang inyong order" ("we're preparing your order"), as if it were final. On November 14 we added the rule "Never say the order is confirmed, final, or ready," and now Jayjay says the order is waiting for staff.

Jayjay takes order requests. It doesn't collect payment, and staff confirm every order by Messenger or phone.
